Using the icons in Windows

Why some icons look bigger than others

Windows always draws icons in the same square. An image that fills the square edge to edge looks big; one with a lot of empty space around it looks small. Turn on Trim transparent edges and use the same padding for every file, then check the preview above. If one icon still looks off (a wide shape like a controller looks shorter than a square folder), set a padding override on that file only.

Set a folder icon

  1. Keep the .ico somewhere permanent first. If you move or delete it later, the folder loses its icon. A good place is inside the folder itself.
  2. Right-click the folder, choose Properties, then Customize, then Change Icon, and browse to the .ico.

Icon not updating?

Windows caches icons. Press Win+R and run ie4uinit.exe -show. If that does not help, restart Windows Explorer from Task Manager.

Gaps between desktop icons

The space between icons is a separate Windows setting and does not change how big an icon looks. Padding here is what controls the visible size.

JPEG always loses some detail, even at 100. Use PNG or WebP lossless to keep every pixel.

Compression

Both are lossless. LZW makes smaller files and opens in all common apps.

BMP files are not compressed, so they are large. Transparent images are saved as 32-bit BMP.

GIF holds at most 256 colors and only fully transparent or fully opaque pixels. Images within those limits convert losslessly; others have their colors reduced and are marked as lossy.

Color and metadata

Other metadata, such as camera details and GPS location, is removed.

Lossless means every pixel in the new file is exactly the same as in the original. After each conversion the tool reopens the new file and compares it with the original, pixel by pixel, and shows “Identical pixels” only when they match.

Converting from JPEG to PNG, WebP lossless or TIFF keeps the image exactly as it is now. It can't bring back detail that JPEG already removed, and the file usually gets bigger.

Not supported yet: saving as AVIF, and opening HEIC photos from iPhones. Animated GIFs and WebPs are converted using their first frame only. 16-bit images are reduced to 8-bit color.
